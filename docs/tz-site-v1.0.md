## 1. Общие сведения

### 1.1 Контекст

Уже работает и протестировано (172 теста, CI):

- **Telegram-бот** @Parscurs77_bot — 16 команд, 3 языка контента (es/ru), алерты, дайджест;
- **FastAPI-бэкенд** — `/api/rates`, `/api/usdt?volume=`, `/api/compare`, `/api/history(.csv)`, `/chart.svg`, `/health`, OpenAPI `/docs`;
- **Источники данных**: Bluelytics + DolarAPI (USD/ARS: oficial, blue, MEP, CCL, tarjeta), CriptoYa (35+ площадок USDT/ARS + пара USDT/USD), BestChange (13 направлений, ARS/USD/RUB), RatesGuru (RUB⇄USDT), Binance P2P (через AR-прокси — в ожидании);
- **История курсов** в SQLite (WAL): точки каждые 15 мин, колонки blue/oficial/MEP/CCL/USDT/USDT-USD;
- **Методология** (фиксируется как контракт): фильтр выбросов ±10% от медианы, спреды по медианам, `totalAsk/totalBid` с комиссиями, семантика compra/venta. См. ревью ТЗ v1.2, раздел 6.2, и реализацию `app/service.py`.

**Сайт — это новый фронтенд-слой поверх существующего API.** Бэкенд-логику (парсеры, методологию, историю) не дублируем.

### 1.2 Цель продукта

Стать основным источником актуальных курсов доллара и USDT в Аргентине для русскоязычной и испаноязычной аудитории: страница каждого курса — под поисковый запрос, с живыми данными, графиками и конверсией в партнёрские переходы на обменники.

### 1.3 Аудитории (персоны)

1. **Житель Аргентины (es)** — гуглит «dolar blue hoy», «ccl hoy», «dolar mep»; хочет курс и где купить.
2. **Русскоязычный в Аргентине / готовящийся к переезду (ru)** — «доллар блю», «usdt аргентина», «как поменять рубли в аргентине»; та же потребность + гайды и арбитраж.
3. **Турист/цифровой кочевник (en)** — «usd to ars blue rate», «usdt buenos aires».

## 4. Архитектура и стек

### 4.1 Схема

```
Пользователь ── Next.js (SSR/ISR, :3000)
                 │  rewrites /api/* → api:8000 (same-origin, без CORS)
                 ▼
              FastAPI (существующий, :8000) ── SQLite (rate_history, clicks)
                 │
                 ├── Bluelytics / DolarAPI (USD)
                 ├── CriptoYa (USDT/ARS, USDT/USD)
                 ├── BestChange / RatesGuru (обменники)
                 └── Binance P2P (прокси, при наличии)
```

- **Фронтенд**: Next.js 15 (App Router) + TypeScript + Tailwind CSS; next-intl для `/es /ru /en`; SWR для клиентского обновления (поллинг 60 с — WebSocket не нужен);
- **Бэкенд**: существующий FastAPI, доработки — раздел 9;
- **Развёртывание (рекомендация)**: тот же docker-compose, сервис `web-next` рядом с `api` и `bot`; единый origin, `/api` проксируется рерайтами Next.js. Альтернатива — Vercel + отдельный домен API (тогда включить CORS на список доменов).
- **Никакой новой БД**: SQLite достаточно (WAL уже включён).

### 4.2 Правила кэширования

- Страницы курсов: ISR `revalidate: 60`;
- API-ответы: `Cache-Control: public, max-age=60, s-maxage=60, stale-while-revalidate=300` (доработка бэкенда, раздел 9);
- Клиент: SWR `refreshInterval: 60000` поверх серверного HTML — данные всегда «не старше минуты» без потери SEO.

## 6. Функциональные требования

Приоритеты: **Must** (обязателен в v1), **Should** (v1, если влезает в срок), **Could** (следующие итерации).

### 6.1 Главная (`/{lang}`) — Must

**Состав**: H1-заголовок с городом/датой; сводная таблица всех курсов (compra/venta, дельта 24 ч со стрелками); топ-3 площадки USDT/ARS; мини-виджет арбитражного коридора; блок «последнее обновление» (из `fetched_at`); ссылки на все страницы курсов; партнёрский блок.

**Данные**: `/api/rates` (SSR) + SWR-обновление.

**Критерии приёмки**: таблица полная (5 типов курса + USDT/USDT-USD); дельты из `/api/history?hours=24`; при недоступности источника — честная пометка «источник недоступен», а не пустая ячейка; LCP мобильный < 2,5 с.

### 6.2 Страница курса (`/{lang}/dolar-{type}`, `usdt-ars`, `usdt-usd`) — Must

Единый шаблон, контент по типу:

| Блок | dolar-* | usdt-ars | usdt-usd |
|---|---|---|---|
| H1 + текущий курс (compra/venta крупно) | ✅ | ✅ (ask/bid) | ✅ |
| Дельта 24 ч / 7 дн | ✅ | ✅ | ✅ |
| График истории (SVG, 7 дн / 30 дн переключатель) | ✅ | ✅ | ✅ (коридор: 2 линии) |
| Таблица площадок (топ-5, кликабельно) | — | ✅ CriptoYa | ✅ (безнал + наличный расчёт + подсказка про cuevas) |
| Партнёрский блок «Где купить/продать» | ✅ (брокеры/банки) | ✅ (обменники BestChange) | ✅ |
| FAQ (3–6 вопросов, JSON-LD FAQPage) | ✅ | ✅ | ✅ |
| Перелинковка на смежные курсы + калькулятор | ✅ | ✅ | ✅ |
| Breadcrumbs (BreadcrumbList JSON-LD) | ✅ | ✅ | ✅ |

**Тексты**: контент-минимум 150–300 слов на страницу (что это за курс, кто использует, как купить — 2–3 абзаца + FAQ). **Цифры курсов в тексты не хардкодить** — только из API (урок ревью ТЗ v1.2: цифры в спеке устаревают за день).

**Критерии приёмки**: страница полностью рендерится сервером без JS (view-source содержит курс, таблицу, FAQ); график — инлайн-SVG из `/chart.svg` (или эквивалент); дельты совпадают с `/api/history`; все ссылки площадок/обменников идут через `/go/{key}`.

### 6.3 Графики истории — Must

- Данные: `/api/history?hours=168|720`; рендер: серверный инлайн-SVG (переиспользовать `history_chart_svg` бэкенда) — без JS-библиотек, нулевой CLS;
- Переключатель периода 24 ч / 7 дн / 30 дн — ссылки (SSR), не SPA-табы, чтобы каждый вид был индексируем (`?period=7d` + canonical).

### 6.4 Сравнение источников (`/{lang}/comparar`) — Should

Перенос экрана `/compare` бота: CriptoYa vs BestChange vs Binance P2P, ранжирование по сторонам, отставание в %, честные «недоступно». Данные `/api/compare`.

### 6.5 Калькулятор (`/{lang}/calculadora`) — Should

5 режимов как в боте (`/calc`): ARS→USDT, USDT→ARS, USD→USDT, USDT→USD, арбитражный цикл. Ввод суммы с толерантным парсером (`1.500,50` / `1,500.50`). Результат: лучшая площадка, сумма, сравнение с медианой. Данные: `/api/usdt?volume=` и `/api/rates`. Для SEO — пресет-ссылки вида `?mode=usdt-ars&amount=100000` (страница отдаёт SSR-результат).

### 6.6 Мастер обмена (`/{lang}/guia`) — Should

Перенос гайда `/how`: 4 сценария с живыми ценами из снапшота. Контент — из i18n-таблицы бота (не дублировать тексты руками).

### 6.7 RUB-направления (`/{lang}/cambio-rub`) — Could

Сбербанк/Т-Банк ⇄ USDT: топ-обменники BestChange + RatesGuru (данные уже есть в бэкенде). Аудитория: русскоязычные, ввод денег из РФ.

### 6.8 О проекте (`/{lang}/about`) — Must

- Методология (ссылка на описание фильтра выбросов и семантики);
- **Раскрытие партнёрских связей** (обязательно: «часть ссылок на обменники партнёрские, это не влияет на порядок в таблицах — порядок только по курсу»);
- Дисклеймер «не является финансовой рекомендацией»;
- Ссылки на бота и API.

### 6.9 i18n — Must

- next-intl, словари `es/ru/en`; за основу es-тексты бота + готовый en-словарь веба;
- `hreflang` es/ru/en + `x-default` → es; единые слаги;
- Форматы чисел/дат — локальные (уже реализовано в `app/formatting.py` — портировать).

### 6.10 Telegram-виджет — Should

Кнопка/баннер «Ещё больше в боте» с deep-link на @Parscurs77_bot (на страницах USDT/арбитража — прямые ссылки на экраны `t.me/Parscurs77_bot?start=...`).

## 7. SEO-требования

1. **Мета-шаблоны** на страницу (title ≤ 60 зн., description ≤ 155, с датой из API): например «Dólar blue hoy: $1.550 (compra/venta) — 22.09.2026».
2. **Structured data**: `FAQPage` (FAQ-блоки), `BreadcrumbList`, `WebSite` + `SearchAction` на главной; `Dataset` для страниц с историей (Could).
3. **sitemap.xml** — генерируется из реестра страниц (app router sitemap), содержит все 42 URL; **robots.txt** — разрешить всё, `Sitemap:`.
4. **Canonical** на каждой странице (сам-на-себя с языковым префиксом), при `?period=`/`?mode=` — canonical на чистый URL.
5. **Скорость**: серверный HTML + инлайн-SVG + Tailwind-минимум; шрифты system-ui или `next/font` с `display: swap`; без тяжёлых JS-библиотек (никаких chart.js/moment). Бюджет Lighthouse: Performance ≥ 90 (mobile), SEO = 100.
6. **Свежесть**: ISR 60 с; в мета и H1 — дата обновления (криптерские «hoy»-запросы любят свежие даты в сниппете).
7. **Перелинковка**: с каждой страницы курса — на все смежные (dolar-blue ↔ dolar-mep ↔ usdt-ars…), на калькулятор с пресетом текущей пары, на гайд.
8. **Тексты под запросы** (без keyword-stuffing): es — «dolar blue hoy», «a cuánto está el blue», «ccl hoy», «dolar mep», «usdt a pesos», «comprar usdt», «vender usdt», «dolar tarjeta»; ru — «доллар блю», «курс доллара аргентина», «usdt аргентина», «как купить usdt в аргентине», «обмен рублей в аргентине»; en — «usd to ars blue», «usdt rate buenos aires», «blue dollar rate today».

## 8. Монетизация (v1)

1. **Механика**: все внешние ссылки на обменники/площадки идут через `GET /go/{key}` (раздел 9) — 302-редирект на целевой URL + запись клика (ts, key, page, lang) в SQLite.
2. **Партнёрские программы** (открытые вопросы — раздел 15): BestChange Partner API (получить partner-id и подставлять в `click.php`), CriptoYa (уточнить наличие), площадки (Binance P2P referral, Ripio, Buenbit и т.д. — Could).
3. **Разметка**: партнёрские ссылки `rel="nofollow sponsored"` (требование Google), `target="_blank" rel="noopener"`.
4. **Честность**: порядок площадок/обменников в таблицах — только по курсу (методология), партнёрство не влияет на сортировку; раскрытие — в `/about` и краткой пометкой в блоках «Где купить».
5. **KPI**: CTR /go/ переходов, топ ключей по кликам (отчёт: `GET /api/admin/clicks.csv` — Could, см. 9.4).

## 9. API-контракт и доработки бэкенда

### 9.1 Существующие эндпоинты (без изменений)

| Эндпоинт | Использование сайтом |
|---|---|
| `GET /api/rates` | Главная, страницы dolar-*, usdt-usd (безнал+нал) |
| `GET /api/usdt?volume=N` | usdt-ars, калькулятор |
| `GET /api/compare` | /comparar, блоки сравнения |
| `GET /api/history?hours=` | дельты, графики |
| `GET /chart.svg?hours=&metric=&lang=` | инлайн-SVG графики (SSR) |
| `GET /api/history.csv` | ссылка «Скачать CSV» |
| `GET /health` | мониторинг |

### 9.2 Новое: `GET /go/{key}` — Must

- 302 на целевой URL; реестр ключей: направления BestChange (`bc:usdt_mp`…), площадки CriptoYa, брокеры/банки USD_URLS;
- целевой URL — из уже существующих в коде (`click.php`, VENUE_URLS) + партнёрский параметр, если получен partner-id;
- запись клика в таблицу `clicks (ts, key, page, lang)`; недействительный ключ → 404;
- referrer-страница передаётся параметром `?p=` (открытый вопрос — допустимо ли хранить).

### 9.3 Новое: Cache-Control на GET /api/* и /chart.svg — Must

`public, max-age=60, s-maxage=60, stale-while-revalidate=300`.

### 9.4 Новое: `GET /api/admin/clicks.csv` — Should

Выдача статистики кликов (защита: заголовок `X-Admin-Token` из env; без токена — 403).
